# Phrase Typer - Автоматический ввод фраз

Программа для автоматического ввода фраз при нажатии горячей клавиши. Полезно для быстрого ввода часто используемых команд
## Установка

1. Установите Python 3.6 или выше
2. Установите зависимости:
```bash
pip install keyboard
```

**Важно:** На Windows может потребоваться запуск от имени администратора для работы с клавиатурой.

## Использование

Запустите программу:
```bash
python phrase_typer.py
```

### 1. Создать/обновить файл с фразами

- Выберите опцию `1`
- Вставьте ваши фразы (каждая строка - отдельная фраза)
- Для завершения ввода:
  - Нажмите Enter дважды (пустая строка)
  - Или введите `END`

Пример:
```
$MP0_CHAR_SET_RP_GIFT_ADMIN
$MP1_CHAR_SET_RP_GIFT_ADMIN
$MP0_SCRIPT_INCREASE_STAM
$MP0_SCRIPT_INCREASE_STRN
```

### 2. Запустить программу ввода фраз

- Выберите опцию `2`
- Программа начнет слушать нажатия клавиш
- **END** - вводит следующую фразу
- **ESC** - выход из программы

Фразы вводятся по порядку, после последней снова начинается с первой.

## Особенности

- ✅ Защита от повторных нажатий (debounce 0.8 сек)
- ✅ Блокировка ввода клавиши END (не попадает в текст)
- ✅ Защита от одновременных вызовов
- ✅ Циклический перебор фраз
- ✅ Автоматическое сохранение в JSON файл

## Файлы

- `phrase_typer.py` - основная программа
- `phrases.json` - файл с сохраненными фразами (создается автоматически)

## Примеры использования

- Ввод статов GTA Online
- Быстрый ввод команд
- Автоматизация повторяющихся действий
- Ввод шаблонных текстов

## Требования

- Python 3.6+
- keyboard (pip install keyboard)

## Примечания

- Программа работает в фоновом режиме после запуска
- Для остановки нажмите ESC
- Фразы сохраняются в формате JSON с кодировкой UTF-8
